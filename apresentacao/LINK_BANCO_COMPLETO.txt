Projeto: Sistema RAG com LLM Local sobre o Project Gutenberg (PAA 2/2026 — UnB)
=============================================================================

Link público (somente leitura) para download do banco de dados completo e índices:
- Pasta raiz no Google Drive: https://drive.google.com/drive/folders/1Wm744_mm06RF32B8KLE8GTGZzVtvFyMr
- Subpasta gutenberg_10gb/ (corpus extraído ~10 GB, 27.740 livros):
  https://drive.google.com/drive/folders/14BuNanzZlVbkopnBvhwSSEuqOCCLmz--
- Subpasta cache_indice/ (índice lexical completo FTS5 ~25 GB + caches amostrais):
  https://drive.google.com/drive/folders/1l1mHa5AF1fph8_gKd0FE36FhSqrpUIUp
- Subpasta cache_indice/ov_Qwen_Qwen2.5-1.5B-Instruct_int8_ff36b9d256/ (~1,46 GiB, modelo LLM OpenVINO IR int8 pré-exportado):
  https://drive.google.com/drive/folders/1q8n85VgS4NsVNPSgO-2emMMDIa23WSGl

Como restaurar localmente após baixar os arquivos do Drive:
1. Colocar os arquivos de `gutenberg_10gb/` (`textos.txt`, `livros.jsonl`, `relatorio.json`)
   dentro de: `dados/gutenberg_10gb/`
2. Colocar os arquivos de `cache_indice/` (`gutenberg_lexical_v1.sqlite`,
   `passagens_gutenberg_v3_20000_42.json`, `embeddings_v1_*.npz`)
   dentro de: `busca/cache_indice/`
3. (Opcional — uso sem `uv` e sem reconversão pesada em CPU/RAM):
   Colocar a pasta `ov_Qwen_Qwen2.5-1.5B-Instruct_int8_ff36b9d256/` dentro de:
   `busca/cache_indice/ov_Qwen_Qwen2.5-1.5B-Instruct_int8_ff36b9d256/`
   Instalar apenas `pip install -r busca\requirements-aceleracao.txt` e definir
   `LLM_MODEL=Qwen/Qwen2.5-1.5B-Instruct` no `.env` (ou `--llm Qwen/Qwen2.5-1.5B-Instruct`).
   Isso pula o download dos pesos originais (~3 GB) e evita reprocessar conversão/quantização
   em CPU/RAM. Ressalva de hardware: funciona em modo `auto` para GPU/CPU Intel; em CPU
   AMD/ARM requer `LLM_BACKEND=openvino`; não acelera em GPUs NVIDIA (CUDA) ou AMD
   (ROCm/DirectML), que usam `torch` ou `onnx` para GPU (mas ainda podem rodar o IR em CPU
   com `LLM_BACKEND=openvino` e `DISPOSITIVO_IA=CPU`).
4. Executar a interface web ou CLI apontando para `--indice-completo`.
